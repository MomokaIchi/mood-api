# mood-api

A RESTful API for logging and managing daily moods. Built with FastAPI to practice backend development, authentication, database design, and clean API architecture.

## Features

- User registration and authentication
- JWT-based authorization
- Create, read, update, and delete mood posts (CRUD)
- Follow and unfollow users
- Protected API endpoints
- Request and response validation with Pydantic
- Interactive API documentation with Swagger UI

## Installation

```bash
git clone https://github.com/MomokaIchi/mood-api.git

cd mood-api

python -m venv venv
```

### Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### macOS / Linux

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Environment Variables

Create a `.env` file in the project root.

```env
SECRET_KEY=your_secret_key
ACCESS_TOKEN_EXPIRE_MINUTES=30
ALGORITHM=HS256
```

---

## Running the Server

```bash
uvicorn main:app --reload
```

The API will be available at:

```text
http://127.0.0.1:8000
```

Swagger UI:

```text
http://127.0.0.1:8000/docs
```

## Authentication Flow

1. User registers an account.
2. User logs in with credentials.
3. Server generates a JWT access token.
4. Client includes the token in the Authorization header.
5. Protected endpoints validate the token before processing requests.
